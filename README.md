# Hati

Endless-scrolling jump-n-run, playable in the browser.
Collect as many points as possible, without touching an obstacle!

[Playable here](https://jtwallis.github.io/games/hati/) (online-scoreboard currently unavailable).
**Ensure that WebGL is enabled in your browser!**

## Setup

To build this project, ensure NodeJS is installed and run:
<br>
<code>npm install</code>

The website can be launched by running:
<br>
<code>npm run dev</code>

Afterwards, it can be viewed on the url:
<br>
<code>http://localhost:8003/games/hati/</code>
<br>

To build this as a static website for production, run:
<br>
<code>npm run build</code>
